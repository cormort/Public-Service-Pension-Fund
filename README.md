# 退撫基金精算決策支援系統 V4

依據公務人員退休撫卹基金第 7 次至第 9 次精算報告書建構之互動式精算分析與政策模擬儀表板。

## 線上展示（GitHub Pages）

- 👉 [https://cormort.github.io/Public-Service-Pension-Fund/](https://cormort.github.io/Public-Service-Pension-Fund/)

## 主要功能

- **基準現況總覽**：第 9 次精算報告公務、教育、軍職人員關鍵指標與第 8 次對照。
- **歷次演變與期間對照**：第 7 至第 9 次精算負債結構堆疊圖與提存率雙軸趨勢，支援任兩期期間差額比較。
- **精算變數敏感度互動探索**：涵蓋折現率、投資報酬率、薪資成長率、平均餘命延長、個人專戶分流與提撥率調整之傳導機制與即時量化試算。
- **進階政策模擬與撥補反推中心**：支援快速情境膠囊、即時聯動滑桿與最低年撥補二分搜尋反推。
- **自訂精算財務推估與資料匯出**：支援 PUC / EAN / TUC 成本法試算、敏感性分析長條圖及現金流 CSV / JSON 匯入匯出。
